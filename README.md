# لولو — Lulu Kids

مشروع Android بسيط ومهيأ للبناء السحابي، بحيث يمكن بناء APK من GitHub بدون كمبيوتر محلي.

## البناء من الهاتف عبر GitHub

1. أنشئ مستودعًا جديدًا على GitHub من الهاتف.
2. ارفع كل ملفات هذا المشروع إلى المستودع، مع مجلد `.github/workflows`.
3. افتح تبويب **Actions**.
4. اختر **Build Lulu APK** ثم **Run workflow**.
5. بعد انتهاء البناء افتح نتيجة التشغيل وابحث عن **Artifacts** ثم نزّل `lulu-debug-apk`.
6. فك الضغط عن الملف الناتج وستجد `app-debug.apk`.
7. ثبّت APK على هاتف Android بعد السماح بالتثبيت من المصدر الذي استخدمته لتنزيل الملف، إذا طلب الهاتف ذلك.

## متطلبات التطوير المحلي
- JDK 17
- Android SDK 35
- Gradle 8.10.2

## ملاحظات
- التطبيق يعمل بواجهة عربية RTL.
- يحتوي على الحروف والألوان والأرقام ومنطقة ولي الأمر.
- يستخدم Android Text-to-Speech لنطق الحروف والأرقام، حسب دعم الجهاز واللغة المثبتة.
- هذا الإصدار MVP قابل للتوسعة، وليس نسخة متجر نهائية.
